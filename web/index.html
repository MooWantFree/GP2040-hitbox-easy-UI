Help

  1. Hold Menu / Start while connecting USB to enter Web Config mode. Use your device's configured shortcut if it differs.
  2. In Layout, drag shapes onto the canvas. Joysticks move as a group; identify each direction separately.
  3. Switch to Identify, select a position, then press its physical button.
  4. Choose outputs in Remap and save. Use More → Restart device to return to game input.

Button labels only change the display, not the firmware input mode. Arcade P / K means punch / kick; actions depend on your game's settings.

Selecting a profile changes what you edit. Use the firmware settings page to change the active profile.

Layouts and physical bindings save automatically and survive restarts. Keep the data folder beside the program when moving it.

Closing the page leaves the program running. Double-click the tray icon to open the page, or right-click it and choose Exit to quit.
